Elligente — About
v1.0.0 · Arc Testnet · @circle-fin/app-kit

Elligente is an open-source batch payment dApp built natively on the Arc Network (testnet, Chain ID 5042002). It uses USDC as gas token and features on-chain ElligentPool for swaps, and CCTP v2 for cross-chain bridges.

Stack
Vanilla JS + ethers.js v6 @circle-fin/app-kit ElligentBatch.sol · ElligentPool.sol WalletConnect v2
Features
Batch up to 500 recipients USDC ↔ EURC swap CCTP v2 bridge On-chain invoices
Released under the MIT License. Free to use, fork, and deploy.
Solidity Contracts (deploy to Arc Testnet)
ElligentBatch.sol — batchTransfer() up to 500 recipients in one tx
ElligentPool.sol — USDC/EURC AMM pool · x·y=k · 0.1% fee
ElligentSwap.sol — swap() pulls liquidity from ElligentPool
ElligentBridge.sol — CCTP v2 cross-chain payments
